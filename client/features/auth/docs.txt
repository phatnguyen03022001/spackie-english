Bước 1: Foundation (Nền móng)
Đừng vội code giao diện. Hãy chuẩn bị các định nghĩa và kết nối server trước.

types/auth.types.ts: Định nghĩa các Interface/DTO cho Login, Register, Respone trả về từ NestJS. (Vì bạn có folder shared từ Prisma, hãy tận dụng các type được generate sẵn ở đây).

api/auth-client.ts: Viết các hàm axios/fetch cơ bản. Ví dụ: login(data: LoginDto), verifyOtp(data: VerifyDto).

Bước 2: Logic Layer (React Query Hooks)
Chuyển các hàm API thuần thành các Hook để quản lý loading, error và cache.

mutations/useRegister.ts & useLogin.ts: Đây là hai luồng chính.

mutations/useSendOtp.ts & useVerifyOtp.ts: Các hàm bổ trợ cho luồng xác thực.

hooks/useAuthSession.ts: Viết logic lưu trữ Token vào Cookies/LocalStorage và quản lý trạng thái User (Zustand hoặc React Context).

Bước 3: UI Components (Features)
Bây giờ mới bắt đầu làm giao diện. Nhờ có các Hook ở Bước 2, bạn chỉ cần "gắn" logic vào các nút bấm.

components/RegisterForm.tsx: Nên làm Register trước để có tài khoản test.

components/LoginForm.tsx.

components/OtpVerification.tsx: Component này quan trọng vì nó được dùng chung cho nhiều luồng (Register, Login 2FA, Forgot Password).

components/ForgotPasswordForm.tsx.

Bước 4: Routing & Integration (App Router)
Cuối cùng là ráp mọi thứ vào cấu trúc thư mục của NextJS.

app/[locale]/(auth)/layout.tsx: Thiết lập khung nhìn chung (background, logo).

Các page.tsx: Import các Form tương ứng từ folder features/auth/components.

index.ts: Export các thành phần cần thiết để sử dụng ở các folder khác (như useAuthSession để check quyền ở Middleware).
