=== DANH SÁCH API HỆ THỐNG SPACKIE ENGLISH (OPTIMIZED) ===


======================================================================
HỆ THỐNG SPACKIE ENGLISH - CẤU TRÚC HỌC TẬP & ĐỒNG BỘ (FRONTEND FOCUS)
======================================================================

----------------------------------------------------------------------
PHẦN 1: CẤU TRÚC XỬ LÝ HỌC TẬP TẠI FRONTEND (BLOCKS)
----------------------------------------------------------------------

1. SM-2 Engine Module (Trí tuệ nhân tạo tại Client)
   - Chức năng: Chứa thuật toán Spaced Repetition (SM-2) phiên bản JavaScript/TypeScript.
   - Hoạt động: Tính toán ngay lập tức các chỉ số (nextReview, interval, easeFactor) dựa trên Grade người dùng chọn (1-4).
   - Lợi ích: Phản hồi UI tức thì (Zero latency), không phụ thuộc vào tốc độ mạng.

2. Local Session Queue (Hàng đợi phiên học)
   - Chức năng: Quản lý danh sách Card trong một lượt học.
   - Hoạt động: Điều phối thứ tự xuất hiện của Card. Nếu chọn "Again" (Grade < 3), thẻ được đẩy xuống cuối hàng đợi để lặp lại cho đến khi thuộc ngay trong phiên học đó.

3. Smart Clustering & Progress Logic (Gom nhóm thông minh)
   - Chức năng: Tính toán % tiến độ của từng Card dựa trên repetition.
   - Công thức: Progress % = (current_repetition / target_repetition) * 100.
   - Hoạt động: Tự động phân loại Card vào các nhóm (30%, 50%, 70%) giúp người dùng tùy chọn "Học tập trung" vào nhóm yếu.

4. Bulk Sync Coordinator (Đồng bộ hàng loạt)
   - Chức năng: Gom kết quả của cả phiên học (Session) để gửi về Server.
   - Hoạt động: Client tích lũy kết quả vào bộ nhớ tạm, sau đó gửi 1 Payload duy nhất chứa mảng dữ liệu đã tính toán xong qua endpoint /sync.

----------------------------------------------------------------------
PHẦN 2: QUẢN LÝ TRẠNG THÁI, GOM NHÓM VÀ ĐỀ XUẤT DECK
----------------------------------------------------------------------

1. Trạng thái "Hoàn thành" của Deck
   - Cơ chế: Tính toán động (Dynamic Status), không lưu field tĩnh trong DB.
   - Điều kiện: Tổng số Card Mastered (repetition > 5) == Tổng số Card trong Deck.
   - Hiển thị: Badge "Mastered" hoặc progress bar 100% trên UI.

2. Gom nhóm Deck (Virtual Collections)
   - Cơ chế: Phân loại ở Frontend từ dữ liệu API getEnrolledDecks.
   - Các nhóm: 
     + "Đang học": Có Card đến hạn hoặc đang trong tiến trình.
     + "Hoàn thành": Đã đạt 100% Mastered.
     + "Cần tập trung": Tỷ lệ thẻ bị "Lapsed" (quên) cao.

3. Cơ chế đề xuất Deck (Recommendation Logic)
   - Theo Level: Xong level A1 -> Gợi ý A2.
   - Theo Topic: Gợi ý các bộ thẻ cùng chủ đề (Công sở, Du lịch, IELTS...).
   - Theo Trending: Gợi ý bộ thẻ có lượt Enroll cao nhất từ cộng đồng.

4. Giải pháp khi "Hết bài để học"
   - API gợi ý Deck mới: Trả về danh sách Deck phù hợp để Enroll thêm.
   - Chế độ Custom Study: Cho phép gom thẻ cũ (nhóm 30%, 50%) để luyện tập (Cramming).
   - Motivational Stats: Hiển thị Heatmap/Streak để giữ chân người dùng.

----------------------------------------------------------------------
PHẦN 3: TỐI ƯU HÓA HỆ THỐNG API (THỪA & THIẾU)
----------------------------------------------------------------------

A. CÁC API CẦN LOẠI BỎ (THỪA)
   - PATCH /vocab/reviews/:cardId/answer: 
     => Lý do: Thừa vì đã có Bulk Sync. Gửi lẻ tẻ làm chậm UI và tăng tải Server.
   - GET /management/vocab/decks/:id/preview (cho học sinh): 
     => Lý do: Có thể gộp thông tin card vào chi tiết Deck khi học sinh khám phá.

B. CÁC API CẦN BỔ SUNG (THIẾU)
   1. [GET] /vocab/cards/all-active:
      - Lấy toàn bộ Card của User (kèm repetition, easeFactor) để Frontend tính toán % và gom nhóm.
   2. [POST] /vocab/reviews/sync (Nâng cấp):
      - Nhận mảng kết quả đã tính toán SM-2 từ Frontend (Server chỉ việc lưu vào DB).
   3. [POST] /vocab/reviews/undo:
      - Hoàn tác kết quả của thẻ vừa bấm (cực kỳ quan trọng cho trải nghiệm người dùng).
   4. [GET] /vocab/decks/recommend:
      - Trả về danh sách Deck gợi ý dựa trên lịch sử học tập.
   5. [GET] /vocab/analytics/stats:
      - Trả về dữ liệu Heatmap, Streak và biểu đồ tăng trưởng từ vựng.

======================================================================


1. NHÓM QUẢN LÝ DECK (MANAGEMENT)
- GET    /vocab/decks/public          : Khám phá các bộ thẻ mới (có kèm đề xuất).
- POST   /vocab/decks/:id/enroll      : Tham gia học bộ thẻ mới.
- DELETE /vocab/decks/:id/unenroll    : Hủy tham gia và xóa tiến độ card liên quan.
- GET    /vocab/decks/enrolled        : Lấy danh sách Deck đang học kèm % hoàn thành.

2. NHÓM LUYỆN TẬP (STUDY ENGINE)
- GET    /vocab/reviews/today         : Lấy thẻ cần học theo lịch (nextReview <= now).
- GET    /vocab/cards/all-active      : Lấy tất cả thẻ đang học để Frontend gom nhóm (30/50/70%).
- POST   /vocab/reviews/sync          : Đồng bộ hàng loạt kết quả đã tính toán từ Client.
- POST   /vocab/reviews/undo          : Hoàn tác kết quả của thẻ vừa trả lời.

3. NHÓM THÔNG MINH (SMART FEATURES)
- GET    /vocab/decks/recommend       : Gợi ý bộ thẻ mới dựa trên trình độ hiện tại.
- GET    /vocab/reviews/cramming      : Lấy danh sách thẻ "yếu" để học cấp tốc.
- GET    /vocab/analytics/stats       : Trả về Heatmap, Streak và biểu đồ tiến độ.

4. NHÓM ADMIN/TEACHER (CONTENT)
- POST   /management/vocab/decks      : Tạo bộ thẻ Master.
- POST   /management/vocab/auto-bulk  : Tự động tạo thẻ từ danh sách từ vựng (AI Fill).
- PATCH  /management/vocab/cards/:id  : Chỉnh sửa nội dung thẻ.
